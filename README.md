# SEwAI Final Project

### Team: Drew Strickland, Anna Kim
## Mario Kart Skill Analysis Project
A web application that evaluates Mario Kart 8 Deluxe races from gameplay videos. A player uploads a video of a race. Then the system reads information from the game's on-screen display, scores the performance, compares it against top players, and suggests ways to improve.

## Current Status
**For reviewers:** The code to evaluate for this milestone is 'PerformanceService.cs' and its tests. Other files are placeholders for planned features.
